# 青州6机组运行状态年度综合分析

## 项目简介

本项目对青州6风电场74台风机2025年度运行状态数据进行全面分析，生成综合性数据分析报告。

## 数据概况

- **机组数量**: 74台风机
- **数据目录**: `青州6机组运行状态-csv/`
- **数据文件**: 1.csv ~ 74.csv
- **时间范围**: 2025-01-01 至 2025-12-01
- **机组型号**: GW252/13600

## 使用方法

### 环境要求

- Python 3.8+
- 依赖库: pandas, numpy, openpyxl

### 安装依赖

```bash
pip install pandas numpy openpyxl
```

### 运行分析

```bash
# 生成完整分析报告和数据表
python3 analyze_turbine_data.py

# (可选) 生成文本可视化摘要
python3 visualize_results.py
```

## 分析维度

### 1️⃣ 基础统计
- 每台机组各运行状态(发电/停机/维护等)的累计时长和占比
- 整体发电利用率计算
- 状态转换频次统计

### 2️⃣ 异常分析
- 识别超长停机事件(>100小时)
- 频繁启停机组识别(状态切换>100次/月)
- 零发电时长机组排查

### 3️⃣ 趋势分析
- 月度发电效率曲线
- 季节性运行特征对比
- 设备健康度评分(基于停机频率和时长)

### 4️⃣ 对比分析
- 机组间性能横向对比
- 识别表现最优/最差的TOP 10机组
- 同型号机组性能差异分析

## 输出文件

### 主报告
- **ANALYSIS_REPORT.md**: 综合分析报告(Markdown格式)
  - 执行摘要
  - 核心发现
  - 异常事件汇总
  - 运维优化建议

1. **turbine_basic_statistics.csv**: 机组基础统计数据
2. **detailed_state_breakdown.csv**: **[新增]** 每台机组详细状态分解（7个状态）
3. **overall_state_distribution.csv**: **[新增]** 整体状态分布汇总
4. **long_shutdown_events.csv**: 超长停机事件明细
5. **frequent_startups.csv**: 频繁启停记录
6. **monthly_trends.csv**: 月度趋势数据
7. **seasonal_analysis.csv**: 季节性分析
8. **equipment_health_scores.csv**: 设备健康度评分
9. **full_comparison.csv**: 机组全面对比
10. **top_10_best_turbines.csv**: TOP 10最佳机组
11. **top_10_worst_turbines.csv**: TOP 10待改进机组

## 关键发现

### 整体表现
- **平均发电利用率**: 37.93%
- **平均设备健康度**: 66.95/100
- **总状态转换次数**: 400,748次

### 🆕 发电利用率低的原因（新增分析）
- **主要原因**: 维护时间过长 **(39.53%)**
  - 维护时间几乎等于发电时间
  - 在非发电时间中占63.7%
- **次要原因**: 停机时间 (17.00%)
- **其他因素**: 待机(4.21%)、启机(1.13%)等影响较小

### 异常情况
- **超长停机事件**: 181次 (>100小时)
- **频繁启停**: 459个机组-月份组合 (>100次/月)
- **零发电机组**: 0台 (✅所有机组均有发电记录)

### 性能差异
- **最高发电利用率**: 80.69% (机组#40)
- **最低发电利用率**: 2.44% (机组#19)
- **利用率差值**: 78.25%

### 季节性特征
- **最佳季节**: 秋季 (76.43%)
- **最差季节**: 冬季 (13.44%)

## 脚本说明

### analyze_turbine_data.py

主要功能模块:

- `parse_csv_file()`: 解析单个CSV文件
- `load_all_data()`: 加载所有风机数据
- `calculate_basic_statistics()`: 计算基础统计指标
- `analyze_anomalies()`: 异常检测分析
- `analyze_trends()`: 趋势分析
- `comparative_analysis()`: 对比分析
- `save_summary_tables()`: 保存汇总数据表
- `generate_report()`: 生成Markdown报告

### visualize_results.py

可视化工具，提供:
- 关键绩效指标(KPI)摘要
- 月度和季节性趋势图表
- TOP 10机组性能对比
- 健康度评分分布

## 技术栈

- **数据处理**: Pandas
- **数值计算**: NumPy
- **文件处理**: CSV, Excel (openpyxl)
- **报告生成**: Markdown
